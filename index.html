AQI Prediction in Taiwan: Comparative Study of Ensemble Learning Methods with SHAP Interpretability

I conducted a comprehensive study benchmarking 11 machine learning and deep learning architectures for hourly Air Quality Index (AQI) forecasting across Taiwan's regional monitoring stations using 2024 EPA sensor data. Models spanning baseline linear regression, boosting methods (XGBoost, LightGBM, CatBoost, GBR), meta-ensemble techniques (Stacking, Bagging, Weighted Voting), and deep learning (LSTM, MLP) were evaluated under a strict temporal train-val-test split to prevent data leakage, with hyperparameters tuned via Optuna. GBR achieved the best performance with an R² of 0.9996, and SHAP analysis identified PM2.5, O₃ 8-hour average, and dominant pollutant category as the top predictive features.

Federated Learning: Gradient Leakage Attacks and Privacy Defenses

Collaborating with a team, we investigated privacy vulnerabilities and defenses in Federated Learning (FL) systems across MNIST, FashionMNIST, and CIFAR-10 datasets. We first demonstrated that gradients alone can leak sensitive training data by implementing a DLG-style Gradient Leakage Attack, successfully reconstructing private client images from shared model updates. Two defense mechanisms were then evaluated: Differential Privacy (DP), which introduces calibrated noise to limit information leakage, and Homomorphic Encryption (HE), which enables fully encrypted server-side aggregation, revealing a clear privacy-accuracy trade-off in DP and a computation-time trade-off in HE.

Explainable Sequence-Based MITRE ATT&CK Technique Detection from Endpoint Telemetry Using AI and Large Language Models

Collaborating with a team, we developed an AI-assisted cybersecurity system for automatically attributing MITRE ATT&CK techniques from Windows/Sysmon endpoint logs using the Splunk Attack Dataset. The project compared classical ML (TF-IDF + SGD), Transformer-based models, and three input representations (event-level, source-file sequences, and sliding-window sequences) across both flat and hierarchical parent-to-sub-technique classification. LLM-Assisted Automated Web Application Penetration Testing Framework

As part of a team, we designed and implemented an end-to-end LLM-augmented automated penetration testing framework for web applications, developed as a final project for the Applying LLMs in Cybersecurity Systems course at NTUST. The system chains ten open-source security tools across a seven-stage pipeline, from reconnaissance and vulnerability assessment to exploit execution and automated report generation, powered by a RAG-backed LLM that reasons over scan findings and assigns standardized CVSS v3.1 severity scores. Validated against OWASP Juice Shop, the framework confirmed 20 solved challenges and produced an overall security score of 39.8/100, demonstrating the practical applicability of LLMs in offensive cybersecurity automation.
